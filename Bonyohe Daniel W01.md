### MCQs Answers



1\. Which of the following is an operating system? 

a) Microsoft Word 

b) Windows 

c) Chrome 

d) Python

Answer: B



2\. Which programming language is commonly used for web development? 

a) HTML 

b) Excel 

c) Photoshop 

d) SQL

Answer: A



3\. In software development, what does GUI stand for? 

a) General User Interaction 

b) Graphical User Interface 

c) Global User Index 

d) General Utility Interface

Answer: B



4\. Which of the following is a version control system? 

a) Git 

b) Python 

c) Java 

d) SQL

Answer: A



5\. What is the purpose of debugging in software? 

a) To design the UI 

b) To find and fix errors 

c) To write documentation 

d) To create graphics

Answer: B
